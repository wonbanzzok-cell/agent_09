# 브라우저 규칙 v1

웹 브라우저를 열거나 제어할 수 있는 작업에는 항상 이 규칙을 적용한다.

## 도구 선택

- 브라우저 작업에는 기본으로 Playwright MCP(`mcp__playwright__*` 도구)를 쓴다.
- Claude in Chrome 같은 다른 브라우저 도구는 사용자가 직접 지정했을 때만 쓴다.

## 자동 호출

- 사용자의 메시지에 아래 키워드 중 하나가 있으면, 먼저 묻지 않고 바로 Playwright MCP를 쓴다.
  - "브라우저를 열어서 작업"
  - "웹 제어"
  - "직접 작업"
  - 비슷한 표현 (예: "브라우저로", "브라우저 열어서", "사이트에 들어가서", "웹에서 직접")

## 동의 후 호출

- 사용자가 키워드를 쓰지 않았더라도 Playwright MCP로 할 수 있는 작업(예: 웹 페이지 확인, 폼 입력, 사이트 클릭 탐색, 스크린샷)이라면, 호출하기 전에 동의를 구한다.
  - 예: "브라우저를 직접 열어서 작업해도 될까요?"
- 사용자가 동의하기 전에는 Playwright MCP 도구를 하나도 호출하지 않는다.
- 사용자가 거절하면 다른 방법으로 작업하거나, 브라우저 없이는 할 수 없는 부분을 설명한다.

## 안전 수칙

- 키워드가 있었더라도 결제, 로그인 정보 입력, 폼 제출, 글 게시처럼 되돌리기 어려운 동작은 실행 전에 사용자에게 확인한다.
- 브라우저 작업이 끝나면 `mcp__playwright__browser_close`로 브라우저를 닫는다.
