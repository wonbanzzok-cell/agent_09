# PPT 규칙 v1

발표자료(.pptx)를 제작하거나 수정할 때는 항상 이 규칙을 적용한다.

## 우선순위

- `mk-ppt` 스킬의 기본값보다 이 규칙을 먼저 적용한다.
- 기준끼리 서로 다르면 다음 순서로 따른다.
  1. 사용자의 요청
  2. 이 규칙
  3. 사용자가 제공한 디자인 관련 `.md` 파일
  4. `mk-ppt` 스킬의 기본 디자인
- 스킬의 기본값은 위 기준이 정하지 않은 항목에만 쓴다.

## 슬라이드 장수

- 기본으로 8장을 제작한다.
- 사용자가 다른 장수를 요청한 경우에만 장수를 바꾼다.

## 디자인 참고

- 제작 전에 사용자가 제공한 디자인 관련 `.md` 파일을 읽고 그 내용을 따른다.
- 사용자가 제공하지 않았다면 시작하기 전에 요청한다.

## 레이아웃과 가독성

- 모든 글은 슬라이드 경계 안에 둔다. 글이 슬라이드 밖으로 튀어나가면 안 된다.
- 글과 도형이 겹쳐서 읽기 어려워지지 않도록 한다.
- 제작 후에는 발표자료를 검사하고, 넘침이나 겹침이 있으면 보고 전에 수정한다.
