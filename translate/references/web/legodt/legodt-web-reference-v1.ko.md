# LEGODT(한국 커스터마이즈 텀블러 브랜드) — 웹 디자인 레퍼런스

- 날짜: 2026-11-01
- 자료: `output/research/legodt/legodt-research-v1.md` (LEGODT 브랜드 소개 페이지. 20~30대(MZ)와 K-pop 팬을 위한 발랄하고 컬러풀한 팝 톤. 비타민 컬러 포인트를 더한 밀키 파스텔 팔레트. TUMGGU = 텀블러 + 꾸미기)
- 출처: GDWEB, DBCUT (Pinterest 사용 안 함)

## 요약

- 이 브랜드에 가장 잘 맞는 레퍼런스들은 **크고 굵은 디스플레이 서체**에 **부드러운 파스텔 컬러 블록**과 **한두 가지 채도 높은 포인트 컬러**를 섞는다. LEGODT 자체 스토어(레퍼런스 1)는 이미 핑크·노랑·페리윙클 바 위에 거대한 검은 워드마크를 올리는 방식으로 이를 보여 준다.
- **어디에나 둥근 형태**: 알약형 버튼, 윗부분이 아치인 카드(배스킨라빈스), 완전히 둥근 패널과 창문 프레임(신한프렌즈), 물결 모양 섹션 경계(콕뭉치). 루프 손잡이가 달린 텀블러와 잘 어울린다.
- **섹션마다 배경색이 바뀐다**(신한프렌즈: 핑크 → 버터, 배스킨라빈스: 흰색 → 핑크 → 나무 → 크림). "내 색을 고르는" 브랜드에 잘 맞는다.
- **컬러 스와치 점이 달린 제품 카드**(LEGODT, 에뛰드, 배스킨라빈스)는 한 제품을 여러 색으로 보여 주는 공통 패턴이다.
- 추천 방향: 밀크 화이트 바탕, 파스텔 섹션 띠(핑크, 민트, 라이트 블루, 애플 그린, 버터, 라벤더), 둥글고 굵은 디스플레이 서체, 비타민 컬러 스티커와 배지, 발랄한 모션(흔들리는 참, 톡 튀어나오는 스티커, 태그라인 마퀴).

## 담을 콘텐츠

리서치 노트에서 가져온 내용:

- **히어로:** "Dress Up Your Tumbler" / "Make it pop. Make it you."와 TUMGGU 개념(텀블러 + 꾸미기).
- **브랜드 스토리:** 오덴세(브랜드웍스코리아, CJ ENM)가 런칭. 컬러풀한 모듈형 식기 라인(2022)에서 텀블러 중심 라이프스타일 브랜드(2023)로 성장. "고르고, 조합하고, 완성한다".
- **특징(숫자):** 6시간 보온·보냉, 새지 않는 뚜껑, 인체공학적 루프 손잡이, 스테인리스 스틸 304, 400ml~1L, 모듈 부품 28개, 180가지 이상의 디자인.
- **꾸미는 방법(5단계):** 텀블러 고르기 → 슬리브·부품 바꾸기 → 참과 키링 달기 → 스티커와 스트랩으로 마무리 → 3D로 미리 보기.
- **라인업:** 루프 텀블러, 루프 텀블러 멀티, 투웨이 루프 텀블러, 트라이탄, 모듈형 텀블러, TUMGGU 액세서리. 컬러명(핑크, 민트, 라이트 그레이, 라이트 블루, 애플 그린, 버터 크림, 라벤더, 오렌지 캐럿, 바닐라).
- **콜라보:** 포켓몬, 망그러진 곰 x 올리브영, 플러피(일본 팝업의 POCA-i 포함).
- **팝업 타임라인:** 2024년부터 2026년 10월까지 한국과 일본에서 열린 날짜가 확인된 팝업 11개.
- **구매처:** 한국(공식 스토어, 오덴세, 29CM, 무신사, 올리브영, 컬리)과 일본(legodt.jp와 팝업만).
- **FAQ:** 일본 오프라인 매장 여부, 보온 시간, TUMGGU란 무엇인지, 소재, 식기세척기 사용 여부(확인 안 됨).
- **SNS 푸터:** @legodt.official(한국), @legodt.japan(일본), 카카오톡 채널.

- **애니메이션 아이디어:**
  - 히어로: 참과 키링이 텀블러에 떨어져 스프링처럼 흔들리고(CSS 키프레임이나 작은 물리 트윈), 스티커는 크기가 튀며(0.6 → 1.1 → 1) "톡" 나타난다.
  - 섹션이 화면에 들어올 때마다 배경이 한 파스텔에서 다음 파스텔로 크로스페이드된다(IntersectionObserver).
  - 호버하면 느려지는 태그라인 마퀴.
  - 원형 배지는 천천히(한 바퀴 20초) 돌고, 호버하면 빨라진다.
  - 단계 카드: 단계마다 텀블러에 한 겹씩 더해지고, 현재 단계 번호에 색이 채워진다.
  - 스와치 클릭: 제품 이미지가 고른 색으로 크로스페이드되고 카드 배경도 같은 색으로 물든다.
  - 타임라인: 화면에 들어오면 루프 선이 스스로 그려진다(SVG stroke-dashoffset).
  - 버튼: 호버하면 흔들리고(±3° 회전), 클릭하면 눌린다.
  - `prefers-reduced-motion`을 존중한다. 회전, 흔들림, 마퀴를 끄고 단순한 페이드만 남긴다.
- **개발 참고 사항:**
  - 모바일 우선: 5단계 고정 레이아웃은 세로 쌓기나 스와이프 캐러셀로, 타임라인은 세로로, 벤토는 2열에서 1열로 바뀐다.
  - 실제 사진이 오기 전까지는 파스텔 배경의 임시 제품 이미지를 쓴다. 레퍼런스 사이트의 로고, 사진, 캐릭터, 문구는 재사용하지 않는다. 콜라보 이름은 텍스트로 쓸 수 있지만 파트너 로고와 캐릭터는 허가가 필요하다.
  - 리서치 노트의 모든 숫자와 날짜(특징, 라인업, 팝업, 채널)를 데이터 파일 하나에 모아, 레이아웃을 건드리지 않고 콘텐츠를 고칠 수 있게 한다.
  - 확인되지 않은 사실(예: 식기세척기 사용 여부)은 콘텐츠에 표시해 사실처럼 보이지 않게 한다. 리서치 노트는 한국 공식 URL을 미확인으로 남겼지만, GDWEB 항목이 https://legodt.kr/ 로 연결되고 그 페이지 제목이 "LEGODT 레고트 공식 스토어"이므로 한국 스토어 링크로 쓸 수 있다.
  - 여러 레퍼런스가 스크롤해서 화면에 들어오기 전까지 콘텐츠를 숨겼다. 자바스크립트가 없거나 애니메이션이 실행되기 전에도 모든 콘텐츠가 보이게 하고(점진적 향상), 전체 페이지 스크린샷으로 테스트한다.
  - 한국어/일본어 전환을 지원한다(최소한 구매처와 타임라인).
